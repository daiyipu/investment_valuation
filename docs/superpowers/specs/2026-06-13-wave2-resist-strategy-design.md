# 波二 & 抵抗 选股策略 — 设计文档

日期：2026-06-13

## Context / 背景

为定增投资开发两个技术型选股策略，复用现有数据底座（qfq 日线、industry_daily 申万行业日线、market_indices 大盘、placement_evaluation 样本脊柱 + PIT 回溯框架）：

- **波二**：长周期"二浪上涨"起始信号（一浪上涨 → 回调 → 二浪重启的触发点）。
- **抵抗**：个股/行业在大盘/行业下跌时的逆势抗跌（相关性背离 + 相对收益确认）。

两者都做成 **PIT 信号函数**（按 `(股票, 日期)` 回算，只用 ≤日期 数据，无泄漏），供屏幕 / 特征 / 预筛三种用法复用。

## 用途（一鱼三吃）

1. **独立选股屏幕**：每日扫全市场（~5000 股），输出波二 / 抵抗股票列表。
2. **定增模型特征**：按每个定增样本报价日 PIT 回算，进 features_derived，提升守价预测。
3. **定增标的预筛**：在定增标的池上跑屏幕，过滤出波二 / 抵抗标的。

## 架构

核心是两个 PIT 信号函数（入参 `stock, date`，内部 ≤date 截断）：

- `wave2_signal(stock, date)` → `{trigger, score, wave1_gain, pullback, breakout_type}`
- `resist_score(stock, date)` → `{corr_diverge_stock, corr_diverge_sector, rel_ret_stock, rel_ret_sector, score}`

三个 runner 复用同一套信号函数：
- **屏幕** `screen_strategies.py --date YYYYMMDD [--universe all|定增池]`
- **特征** derive_features 末尾续编 H(波二) / I(抵抗) 类，按报价日回算
- **预筛** 屏幕在定增标的池上跑

## 数据

- 个股 qfq 日线：`market_data.price_series`（已 qfq）/ 按股 `pro_bar(adj='qfq')`
- 行业日线：`industry_daily`（SW 指数，`index_code + trade_date`）
- 大盘：`market_indices` / `market_index`
- PIT：信号函数 ≤date 截断；屏幕按当日、特征按报价日，**天然复用现有回溯框架**

## 策略一：波二（二浪调整末端 → 三浪主升启动）

> ⚠ **【待定】波二定义有疑问**：当前按"二浪调整末端→三浪主升启动"执行，后续可能调整。

> 经典波浪理论：**二浪是调整浪**（对一浪的反向回调，回撤斐波那契 0.382~0.618，铁律不破一浪起点）；二浪末端是三浪（主升）启动前的入场点。本信号 = **二浪调整末端转折、三浪主升启动**的买入信号（"波二起始"= 调整浪2 的末端转折）。

按 date 回算（≤date 的 qfq 收盘）：

1. **长周期上行**：close > MA120 且 MA120 近 20 日斜率 > 0（长周期主趋势向上）。
2. **一浪（主升 1）确认**：前 60~120 日内阶段低点→高点涨幅 ≥ 20%（确认有过一波明显上涨）。
3. **二浪（调整）特征**：从一浪高点回撤 **38.2%~61.8%**（斐波那契标准），且**不破一浪起点（前期低点）—— 铁律**；MA60/MA120 作辅助支撑确认。
4. **三浪启动信号（触发日）**：close **突破二浪（回调）高点** = 调整结束、主升重启；辅以 MA5 上穿 MA20 / 量比 > 1.2。

- `trigger = 1 ∧ 2 ∧ 3 ∧ 4`
- `score = 一浪涨幅 × 突破强度`

## 策略二：抵抗（相关性背离 + 下跌波段抗跌方向）

按 date 回算：

### A. 相关性背离（多窗口 5/10/20 日，更精准）

- **个股-行业** & **行业-大盘**：基线 corr = 60 日 corr（要求 ≥ 0.4，常态高相关才算"背离"，分母也稳）。
- 近 W 日 corr，**W ∈ {5, 10, 20}**：分别算 5 日、10 日、20 日三个近期 corr，捕捉短/中/稍长多尺度脱钩，监控跨度更长、更精准。
- 各窗背离分 = `(基线corr − 近W日corr) / 基线corr`（归一化，按比例衡量脱钩程度，跨股可比）。
- `背离分综合 = mean(背离分_5d, 背离分_10d, 背离分_20d)`（多窗平均更稳；可选要求多窗一致更严）。

### B. 下跌波段抗跌方向（方向确认）

- **大盘下跌波段**：date 前近期高点（近 30 日内最高）回落 > 5% → `[peak, date]` 为下跌波段。
- **行业抗跌**：波段内 `(行业收益 − 大盘收益) > 0`。
- **个股抗跌**：行业同期下跌波段内 `(个股收益 − 行业收益) > 0`。
- 这一步区分**抵抗性脱钩**（脱钩是因为扛住了）vs **补跌性脱钩**（脱钩是因为崩了）——只认前者。

### C. 综合

- **个股抵抗分** = 个股背离分综合(个股-行业) × 个股相对收益(下跌波段内 个股 vs 行业)
- **行业抵抗分** = 行业背离分综合(行业-大盘) × 行业相对收益(下跌波段内 行业 vs 大盘)
- `抵抗成立 = 个股背离分综合 > 阈值(默认 0.4) ∧ 个股相对收益 > 0`（个股自身脱钩 + 抗跌方向）
- `score = 0.5 × 个股抵抗分 + 0.5 × 行业抵抗分`（个股抵抗为主，所处行业的抵抗作加成；权重可调）

## 输出

- **屏幕**：
  - 波二列表：股票 / 一浪涨幅 / 回撤 / 触发类型，按 score 排序 CSV。
  - 抵抗列表：股票 / 个股背离分 / 行业背离分 / 相对收益 / 综合分，按 score 排序 CSV。
- **特征**：`波二_trigger / 波二_score / 抵抗_个股背离 / 抵抗_行业背离 / 抵抗_综合` 进 features_derived。

## 默认参数（可调，先看效果后调）

- **波二**：一浪涨幅 ≥ 20%、回撤 38.2~61.8%（斐波那契）、不破一浪起点（铁律）+ MA60 辅助、长周期 MA120/MA250、突破 = 突破二浪高点 / MA5 穿 MA20、量比 > 1.2（可选）。
- **抵抗**：基线窗 60 日、近窗 5/10/20 日(多窗)、基线 corr ≥ 0.4、背离分综合阈值 0.4、下跌波段回撤 > 5%、波段高点取近 30 日最高、综合加权 0.5 个股 + 0.5 行业。

## 复用

- 取数：`market_data` / `industry_daily` / `market_indices` 现有 PIT 回溯（load_db_features 范式）。
- 信号函数纯计算，三 runner 共享。
- 特征接入：derive_features 末尾续编 H(波二) / I(抵抗) 类，仿现有 F/G 类"批量读明细 + 按报价日回算"。

## 验证

- **屏幕**：跑一个历史交易日（如最近收盘日），看波二 / 抵抗列表是否合理（人工抽查几只熟悉的股票）。
- **特征**：回算后看 IV / 覆盖率；进评分卡看是否入选、validate AUC 是否提升。
- **PIT 抽查**：信号只用 ≤date 数据，无未来信息。
