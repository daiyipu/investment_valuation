### 评分公式
**总分 = 50 + Σ(各特征分箱得分)**

- 基础分：50分
- 每个特征根据其数值落在不同分箱贡献不同得分（-10到+10分）
- 最终总分接近0-100分制
- **得分越高，定增盈利概率越大**

- 个股PB: 3.0 → 落在(2.574, 3.389] → +1.48分

- sue_zscore: -1.5 → 落在(-25298258.205, -0.236] → +10.33分
- smc_fvg_net_W: -3.0 → 落在(-7.001, -1.0] → +4.59分
- mf_main_net_ratio_5d: -0.05 → 落在(-0.175, -0.0322] → +5.25分

**最终得分** = 50 + 1.48 + 0.82 + 10.33 + 4.59 + 5.25 + ... (其余13个特征得分)

**得分解释**：
- **60分以下**: 低盈利概率，谨慎参与
- **60-70分**: 中等盈利概率，可考虑参与
- **70-80分**: 高盈利概率，建议参与
- **80分以上**: 极高盈利概率，重点关注
